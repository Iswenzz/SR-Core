# Q3

API for Q3-style maps with custom weapons, perks, and section triggers.

## Default weapons

All maps start with these weapons by default:

| Weapon | ID |
|--------|----|
| Rocket | `gl_ak47_mp` |
| Plasma | `gl_g3_mp` |

Override them with `sr\api\_q3::weapons(...)`.

### `sr\api\_q3::createSection(<id>, <origin>, <width>, <height>, <callback>)`

Creates a trigger that calls a function when a player enters it.

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | string | Unique section ID |
| `origin` | vector | Trigger center position |
| `width` | float | Trigger width |
| `height` | float | Trigger height |
| `callback` | function | Function to call when triggered |

```c
sr\api\_q3::createSection("section_1", (0, 0, 0), 150, 100, ::section1);
```

Creates a trigger that gives the player a Q3 weapon when entered.

### `sr\api\_q3::setWeapons(<list>)`

### `sr\api\_q3::createTeleporter(<id>, <origin>, <width>, <height>, <destination>)`

Creates a trigger that moves the player to a named `script_struct`, facing the way it faces, with speed reset the way Quake's teleporters do.

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | string | Unique trigger ID |
| `origin` | vector | Trigger center position |
| `width` | float | Trigger width |
| `height` | float | Trigger height |
| `destination` | string | `targetname` of the struct to arrive at |

```c
sr\api\_q3::createTeleporter("tele_1", (0, 0, 0), 150, 100, "target_teleporter3");
```

Players are notified `q3_teleported` with the destination when they arrive.

## Converted maps

Maps converted from Quake 3 by IzFF carry these entities. The core picks them up automatically —
nothing in the map script has to call the api for them.

| `targetname` | Keys | What it does |
|---|---|---|
| `q3_weapon` | `weapon`, `ammo`, `id` | Gives the weapon and switches to it |
| `q3_ammo` | `weapon`, `ammo`, `id` | Tops up that weapon's ammo |
| `q3_perk` | `perk`, `time`, `id` | Grants the perk for `time` seconds |
| `q3_health` | `health`, `id` | Heals |
| `q3_armor` | `armor`, `id` | Gives armor |
| `q3_section` | any of the above, `checkpoint`, `target`, `id` | Hands out whatever the map's `target_give` chain granted, and notifies `q3_checkpoint` when it also marks progress |
| `q3_teleporter` | `target`, `id` | Moves the player to the `script_struct` it targets, facing its angles, with speed reset |
| `q3_door` | `move`, `speed`, `time`, `target` | Opens on approach, waits, closes |
| `q3_button` | `move`, `speed`, `time`, `target` | Sinks in when touched and notifies `q3_button` on everything it targets |

`move` is a `"x y z"` string: how far the brush travels when open, worked out by the converter
from the brush's own size less its lip, since a script cannot measure a brush model.

The map's own triggers keep Quake's link: `q3_teleporter`, `startmap_trig`, `endmap_trig`,
`checkpoint_trig` and `push` all carry a `target` naming the `script_struct` that holds the
destination.
