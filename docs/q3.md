# Q3

API for Q3-style maps with custom weapons, perks, and section triggers.

## Default weapons

All maps start with these weapons by default:

| Weapon | ID |
|--------|----|
| Rocket | `gl_ak47_mp` |
| Plasma | `gl_g3_mp` |

Override them with `sr\api\_q3::weapons(...)`.

### `sr\api\_q3::createSection(<id>, <origin>, <width>, <height>, <callback>)`

Creates a trigger that calls a function when a player enters it.

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | string | Unique section ID |
| `origin` | vector | Trigger center position |
| `width` | float | Trigger width |
| `height` | float | Trigger height |
| `callback` | function | Function to call when triggered |

```c
sr\api\_q3::createSection("section_1", (0, 0, 0), 150, 100, ::section1);
```

---

### `sr\api\_q3::createWeapon(<id>, <origin>, <width>, <height>, <weapon>, <?ammo>)`

Creates a trigger that gives the player a Q3 weapon when entered.

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | string | Unique trigger ID |
| `origin` | vector | Trigger center position |
| `width` | float | Trigger width |
| `height` | float | Trigger height |
| `weapon` | string | Q3 weapon ID |
| `ammo` | int | *(optional)* Ammo count — omit to give max ammo |

```c
sr\api\_q3::createWeapon("rocket_1", (0, 0, 0), 150, 100, "gl_ak47_mp", 4);
```

---

### `sr\api\_q3::createPerk(<id>, <origin>, <width>, <height>, <perk>, <?time>)`

Creates a trigger that gives the player a Q3 perk when entered.

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | string | Unique trigger ID |
| `origin` | vector | Trigger center position |
| `width` | float | Trigger width |
| `height` | float | Trigger height |
| `perk` | string | Perk ID |
| `time` | float | *(optional)* Duration in seconds — omit for permanent |

```c
sr\api\_q3::createPerk("haste_1", (0, 0, 0), 150, 100, "haste", 4);
```

---

### `sr\api\_q3::setWeapons(<list>)`

Sets the default weapons given to players on spawn. Weapon IDs are separated by `;`.

| Parameter | Type | Description |
|-----------|------|-------------|
| `list` | string | Semicolon-separated list of weapon IDs |

```c
sr\api\_q3::setWeapons("gl_ak47_mp;gl_g3_mp;");
```

---

### `sr\api\_q3::setPerks(<list>)`

Sets the default perks given to players on spawn. Perk IDs are separated by `;`.

| Parameter | Type | Description |
|-----------|------|-------------|
| `list` | string | Semicolon-separated list of perk IDs |

```c
sr\api\_q3::setPerks("haste;");
```

### `switchToWeapon(<name>)`

Switch to a Q3 weapon.

| Parameter | Type | Description |
|-----------|------|-------------|
| `name` | string | Q3 weapon ID |

```c
player sr\api\_q3::switchToWeapon("gl_ak47_mp");
```

---

### `<client> sr\api\_q3::takeWeapon(<name>)`

Removes a Q3 weapon from the player.

| Parameter | Type | Description |
|-----------|------|-------------|
| `name` | string | Q3 weapon ID |

```c
player sr\api\_q3::takeWeapon("gl_ak47_mp");
```

---

### `<client> sr\api\_q3::takePerk(<id>)`

Removes a specific Q3 perk from the player.

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | string | Perk ID |

```c
player sr\api\_q3::takePerk("haste");
```

---

### `<client> sr\api\_q3::takeAllPerks()`

Removes all Q3 perks from the player.

```c
player sr\api\_q3::takeAllPerks();
```

---

### `<client> sr\api\_q3::giveWeapon(<name>, <?ammo>)`

Gives the player a Q3 weapon. If `ammo` is omitted, max ammo is given.

| Parameter | Type | Description |
|-----------|------|-------------|
| `name` | string | Q3 weapon ID |
| `ammo` | int | *(optional)* Ammo count |

```c
player sr\api\_q3::giveWeapon("gl_ak47_mp", 4);
```

---

### `<client> sr\api\_q3::givePerk(<id>, <?time>)`

Gives the player a Q3 perk. If `time` is omitted, the perk lasts forever.

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | string | Perk ID |
| `time` | float | *(optional)* Duration in seconds |

```c
player sr\api\_q3::givePerk("haste", 4);
```
